# QLAB

Sistema de Agendamento de Laboratórios de Informática

## Sobre

QLAB é um sistema desktop para gerenciamento de reservas dos laboratórios de informática do IFPE Campus Paulista.

## Tecnologias

- Java
- Java Swing
- MySQL

## Estrutura do Projeto
```
qlab/
├── src/
│   ├── main/
│   ├── model/
│   ├── view/
│   ├── controller/
│   └── dao/
├── database/
│   └── schema.sql
└── README.md
```
